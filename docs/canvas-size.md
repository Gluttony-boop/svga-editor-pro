# 画布尺寸

右侧“属性”面板的“画布尺寸”用于修改 SVGA 的 `viewBox` 宽高。输入宽度或高度后按 Enter/失焦应用，Esc 取消；“锁定比例”会根据当前画布比例计算另一边。

尺寸修改会同步实时预览、画布控制框、画布对齐参考线和 SVGA 导出，并写入一条可撤销历史。播放会先暂停，原始图层坐标、逐帧运动、关键帧、缩放和旋转不会被自动改写；因此新边界之外的内容会被裁切，扩大画布则会保留原坐标并产生更多透明区域。这是有意保持动画坐标稳定的合成尺寸编辑语义。

安全限制：单边 1–8192 px，像素总数不超过 4,194,304。宽高必须为整数。修改尺寸不会改变 FPS、总帧数或音频；导出预览与最终 SVGA 文件会使用新尺寸。

撤销/重做会同时恢复编辑器参数、渲染器画布和 `videoItem.movie.params`，不会原地污染打开文件的原始对象。

导出面板提供“按当前画布自动缩减图片尺寸”。启用后，导出优化器会把当前画布宽高作为图片纹理的最大边界，逐张等比缩小超出边界的图片；也可以与手动缩放百分比和最大宽高同时使用，取更严格的限制。该功能只改变导出文件中的图片像素，不改变画布 `viewBox`、图层坐标、变换、遮罩或动画时序。对于原文件中缺少完整 `layout` 的帧，导出时会保留其原始固有显示尺寸，避免纹理降采样导致画面意外变小。

“按指定尺寸缩减图片”可单独设置最大宽度和最大高度，例如 `256 × 256 px`。两边是等比上限，不会拉伸、裁切或放大较小图片；只填写一边时按另一边的原始比例计算。它与百分比缩放、按画布自动缩图可以同时启用，最终取更严格的限制。尺寸设置只作用于导出优化纹理，不会修改工程中的原始图片或图层布局；图片编码后没有变小、或整包变大时，优化器会保留原图/未优化副本。
