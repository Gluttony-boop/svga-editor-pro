# 图片 Key、文字范围与 SVGA 文字交付

文字模拟用于让设计师在原动画上预览昵称、标题、标签等文案。文字绑定到现有图片 Key，跟随对应图层的位置、缩放、旋转、透明度和时间变化，不会新建一条独立文字图层。可以扩大文字显示范围，并选择只模拟文案，或把当前固定字形写入导出的 SVGA 动画。

## Key 识别的边界

SVGA 精灵提供的是 `imageKey`，没有独立的 `textKey` 字段。播放器的动态文字也依附于图片 Key。因此面板区分的是图片资源、疑似文字用途和已经配置的文字，而不是宣称从文件中读取到了文字类型。

- Key 列表包含当前图层的精确 Key、未引用的图片资源和已有的孤立配置。可搜索完整或部分 Key，名称比较不区分大小写，但配置绑定使用原始精确字符串。
- `$`、`@`、空白、数字字符串和大小写都不被截断或修改。例如 `$name@2` 不会被改成 `name`。
- “疑似文字”仅根据 `text`、`label`、`title`、`nickname`、`username`、`文字`、`昵称` 等命名提示推测。普通图片 Key 也能配置文字；`contexture`、`button_name` 不会仅因相似片段被当成文字。
- “已配置文字”表示存在文字配置，即使文案为空或暂时关闭模拟也仍保留该配置。
- 未引用资源会留在列表中，但不能因为资源存在就声称动画中有可调用的插槽。删除所有图层后，不会重新从原始精灵列表恢复已删除的引用。
- 遮罩 Key、以 `.matte` 结尾的 Key 和包含矢量形状的 Key 为只读文字目标。使用遮罩的内容层仍可以模拟文字，文字会受到原遮罩裁切。
- 根据音频轨道引用和常见音频文件头识别的音频资源不会混入图片/文字 Key 列表。

## 操作流程

1. 打开 SVGA，进入右侧“插槽”面板。
2. 搜索并选择 Key，查看图片资源状态、参考尺寸、当前图层引用和限制提示。可定位到引用它的图层。
3. 输入模拟文案，调整字号、颜色、字体、粗体、对齐、横纵偏移、行高和多行内容。
4. 文案显示不全时，在“文字显示范围”调整“文字框宽度/高度”，或点击“加宽 100 px”。按 Enter 或失焦应用，Esc 放弃当前数字草稿；不会为了容纳文字而自动缩小字号。
5. 在预览画布中播放或逐帧检查。切换显隐可对比原效果，“仅显示文字”用于在文字可见时隐藏同一 Key 的底图。
6. 在“SVGA 文字导出”选择“仅模拟文字（范围仍生效）”或“写入 SVGA（固定字形）”，然后正常导出完整动画。
7. 保存 `.svgaproj` 保留可编辑文案；需要开发接入时可另存文字配置 JSON，并核对它与实际交付的 SVGA 是否一致。

同一 Key 被多个图层共用时，配置同时作用于全部引用，不只影响当前选中图层。隐藏的图层仍保留引用，但遵循图层自身的隐藏状态。修改图层显示名称不会改变实际绑定的 Key。

图片替换和文字模拟可以同时配置在同一个 Key 上。加宽文字框不改变替换图片的目标适配尺寸。清除文字模拟会一并移除该文字配置的显示范围和导出模式，图片替换仍保留；恢复图片也不需要丢弃已有文案。

## 尺寸与显示

尚未设置文字框的旧配置保持原行为：文字使用各原始帧的布局尺寸排版，布局不可用时才回退到图片尺寸；不会自动建立新的范围或改为写入字形。替换为像素尺寸不同的图片不改变文字布局基准。

首次修改宽高或开启“写入 SVGA”时，以 Key 首个有效布局的向上取整尺寸建立固定参考 `referenceWidth/referenceHeight`，并同时保存文字框 `boxWidth/boxHeight`。此后尺寸都位于这套固定局部坐标内，以源图左上角为锚点；加宽向右扩展，加高向下扩展，不移动底图、不拉伸底图或字号。居中和右对齐会按新文字框重新排版，所以文字位置可变化。

例如原布局为 **100 × 50 px**，文字为 `2222222222222`：将文字框宽度改成 **300 px** 后，可在 **300 × 50 px** 范围内显示文字，底图仍占原来的 **100 × 50 px**，24 px 字号也仍为 24 px。若原动画后续帧的布局变为 **200 × 100 px**，新的显示范围随原动画同比例变为 **600 × 100 px**；这时底图和文字随原动画放大，而不是文字框设置额外把底图拉长。原位置、缩放、旋转、透明度、时间和关键帧继续生效。

“恢复原尺寸”在仅模拟模式下移除四个尺寸字段，回到旧的逐帧排版；在写入模式下将文字框恢复为参考尺寸，但保留参考字段以维持一致的字形纹理，不擅自切换导出模式。

列表显示首个有效参考尺寸，不代表所有引用和每一帧都是这个尺寸。不同引用的尺寸或资源元数据冲突时会显示警告，实时画面以当前帧布局为准。没有位图但存在有效图片图层布局时，可以显示文字，并提示缺失底图。

缺少有效尺寸、没有图片图层引用、使用遮罩/矢量 Key，或参考区域超过单边 8192 像素/总计 4,194,304 像素时，不开放文字模拟。显式文字框的四个尺寸必须同时存在，为 1–8192 的整数；文字框、参考区域及二者合成区域均不能超过 4,194,304 像素。合成区域按 `max(boxWidth, referenceWidth) × max(boxHeight, referenceHeight)` 校验，因此“极宽但很矮的文字框 + 极窄但很高的底图”也可能超限。超限会明确拒绝，不静默截小；渲染器独立检查离屏分配尺寸。

多行文字以换行符分行，不自动执行段落排版。文字超出文字框时仍会裁切；可以继续加宽、调整字号或偏移、手动换行。文字框变窄只裁文字，不主动裁掉保留的底图。原图层 `clipPath`、遮罩和动画画布 `viewBox` 继续限制显示，加宽不能绕过这些边界。

字体采用当前系统可用字体，不随工程或 JSON 嵌入。仅模拟或按 JSON 在终端动态绘字时，不同平台的字体回退和字形度量可能不同；写入模式将导出时本机实际渲染的字形栅格化，接收端无需安装该字体即可显示图片字形，但重新打开工程改字仍受本机字体影响。

## 保存与交付

- **仅模拟（默认）**：`exportMode` 缺省或为 `preview`。配置过的文字框通过透明扩容图片和调整逐帧 `layout` 写入 SVGA，但文案本身不写入。未设置范围的旧配置保持原素材/替换图行为，不自动烘焙文字。
- **写入 SVGA（固定字形）**：`exportMode` 为 `bake`，且必须包含完整文字框和参考尺寸。将启用且非空的文字合成进对应图片资源，并保留逐帧动画；生成的是完整动画，不是当前画布的一张截图。Key 仍遵循既有图层命名与兼容性规则，请核对实际文件。字形已成为图片，不能用普通文本编辑直接改掉；若接入端再次叠加相同文案，会造成重复文字。
- 关闭“显示文字”或文案为空时，即使模式为 `bake`、勾选“仅显示文字”，也不绘字、不隐藏底图；已配置的范围仍保留。正常的图层隐藏、透明度与裁切仍生效。
- `.svgaproj` 始终保留可编辑文字、范围、导出模式和未破坏的源数据。仅重新打开导出的 `.svga` 不能恢复已经栅格化字形的可编辑文本；应保留工程供后续修改。
- PNG/WebP 等画面导出包含当前启用的可见文字效果，不受“仅模拟/写入 SVGA”的选择影响。
- 文字配置 JSON 只记录精确 Key、文案样式与拟采用的导出模式，**不证明任何 SVGA 已按这些配置生成**。开发者需核对实际交付文件，按目标播放器 API 适配动态文字，避免对已带字形的资源再叠字。它不是所有播放器通用的直接导入协议，目前也不支持将该 JSON 单独导入编辑器。
- 已经被制作软件栅格化进图片的文字无法由 Key 名称恢复。这不是 OCR，也不能自动区分底图中的文字和其他图案。“仅文字”会隐藏整个对应底图，不是从图片中擦除原来的字。

这些字段是编辑器工程配置，不是新增的 SVGA `textKey` 或文字协议。新版本能读取缺少新字段的旧工程；旧版本的工程校验器会严格拒绝包含新尺寸或导出模式字段的工程，这不是双向兼容。详细字段与校验见 [工程格式](project-format.md)。

## 验证范围

Key 单元测试覆盖精确字符串、特殊 Key 与原型安全、稳定去重、重命名/删除图层、共享引用、未引用资源、图片签名、音频排除、遮罩/矢量分类、无效尺寸和尺寸冲突。解析器检测测试确保不再剥离 `$...@...` 命名，并将文字命名标记为候选提示。

既有文字模拟流程已在 Edge 中验证示例/多行文字的实时像素变化、颜色与字号、两种渲染器一致性、播放、显隐、仅文字、单次输入历史、Esc 像素恢复、换图/恢复图片时文字保留，以及 `$title@2` 的精确绑定与 JSON 交付。旧轮次的真实编码回读验证针对默认模拟模式，不代表本轮新增文字框与写入模式的完整浏览器验收。

本轮工程与历史定向测试覆盖新字段真实 ZIP 往返、旧工程缺字段兼容、不完整尺寸组、整数/面积上限、写入模式必须有参考尺寸、一次提交/撤销、取消草稿以及换图保留范围。新增编码回归包含共享/复制/重命名 Key、保留后缀、缺省布局与原图尺寸不一致、源图/替换图预算、遮罩引用及安全资源命名。`__proto__` 等无法被常见 JS 播放器安全读取的导出资源名会映射为安全 Key；原文件在解码时已丢失该资源则明确拒绝，不能声称完整兼容。字体与复杂 SVGA 仍应在目标播放器上验收。
