# 历史记录

历史记录面板默认停靠在右侧检查器下方。可以拖动上边缘调整高度，点击标题折叠，点击关闭按钮隐藏；通过工具栏的历史记录按钮或「视图 → 显示历史记录」重新打开。

## 回退和恢复

- 每行代表该操作完成后的状态。点击任意一行，直接恢复到那一步；高亮和左侧箭头标记当前状态。
- 回退后的步骤变灰，但仍可点击恢复。此时继续编辑会删除这些后续步骤，产生新的线性历史。
- 撤销、重做按钮及 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`、`Ctrl/Cmd+Y` 与面板同步。列表内可用上下方向键及 Home/End 切换状态。
- 「删除当前状态」会在确认后恢复到上一步，同时删除所选状态和后续步骤；不能删除起点。
- 「清空历史记录」需要确认，保留当前画面和快照，但清空全部撤销、重做步骤。删除和清空操作不可撤销。

以上采用 Photoshop 历史记录的默认线性模式；参见 [Adobe 历史状态说明](https://helpx.adobe.com/photoshop/desktop/get-started/set-up-toolbars-panels/manage-image-states.html)。

## 快照

- 打开文件后自动保存一个「打开」快照。
- 点击面板底部的相机按钮，为当前完整编辑状态创建命名快照。双击快照可重命名。
- 点击快照即可查看该状态，不增加操作步骤；仍可点击原有历史步骤返回。
- 在快照上继续编辑时，原有操作步骤会被新分支替换，其他快照保留。
- 删除快照只移除这个书签，不修改当前画面或原时间线。

快照与操作历史仅属于当前文件会话，不写入 SVGA 文件；关闭或打开其他文件后会重置。快照交互参照 [Adobe 快照说明](https://helpx.adobe.com/photoshop/desktop/get-started/set-up-toolbars-panels/create-work-snapshots.html)。

## 范围

最多保留最近 100 个编辑步骤；达到上限时，起点标签随被裁剪的步骤更新，「打开」快照仍可恢复最初状态。记录涵盖图层、变换、关键帧、资源、插槽、动画参数和导出配置。预览播放、缩放、面板切换和单纯选择图层不新增历史步骤。
