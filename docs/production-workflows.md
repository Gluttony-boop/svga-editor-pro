# 生产与编辑工作流

适用于提交 `867615a` 的功能。保存 `.svgaproj` 保留可编辑工程；导出 `.svga` 是播放产物，不能替代工程备份。以下预览与检查不代表目标 SDK、设备或全部商业部署已完成验收。

## 从首页任务开始

未打开文件时，可选择四个任务，也可“跳过任务入口”直接打开自己的动画；之后可点“显示任务入口”恢复。示例打开后，“打开操作入口”可再次定位相关面板，“关闭引导”只关闭提示。

| 任务 | 推荐操作 |
| --- | --- |
| 换头像昵称 | 替换 `avatar`，比较单层与全部引用；在插槽中修改 `nickname_text` 的文字和显示范围。昵称默认仅模拟，固定写入 SVGA 需选择转图片方式。 |
| 压缩到指定大小 | 在导出面板输入“目标大小（KiB）”，调整优化设置并生成导出预览，再核对实际体积与画质。目标只是核对标准，不会自动压到指定大小，也不阻止超标导出。 |
| 批量生成 | 使用示例作为模板，按下述四步生成多份文案交付包。 |
| 检查交付 | 打开专业交付包，设置目标播放器和体积预算，生成后查看报告与实际 SVGA 预览；仍需在目标设备上实测。 |

四套示例为本机生成的原创几何动画，素材和动画数据采用 CC0，可修改、商用，无需署名；不含第三方头像或字体文件。`avatar` 由两层共享，适合验证替换范围。字体和后来导入的素材需自行确认授权，详见 [示例授权](./task-example-license.md)。

## 批量生产：选择模板 → 导入数据 → 核对预览 → 生成结果

入口：检查器“插槽”→“批量生产 / 恢复任务…”。目前只支持批量文案，每批最多 **100 条数据记录**（CSV 表头不计入），图片批量处理尚未开放。

1. 选择模板：使用当前工程创建独立快照，或导入本地 `.svgaproj`（不超过 128 MiB）。这不会替换当前画布或增加撤销记录。后续画布修改不会进入此批，需回到第 1 步重新选择模板。
2. 导入数据：选择要替换的精确文字 Key，导入不超过 8 MiB 的 UTF-8 CSV/JSON，也可粘贴或“填入示例”。CSV 用 `id` 列作唯一编号，其他列名与所选 Key 完全一致；JSON 推荐 `[{"id":"001","values":{"nickname_text":"小雨"}}]`。每条文案长度上限可设为 1–500 个 Unicode 码点。点击“核对数据并预览”，先修正全部问题行；数据规则通过不等于文字不会裁切。
3. 核对预览：明确选择“动态接入”或“固定字形”，选择抽样记录并点“生成此条双预览”。动态接入把文案交给开发，实际 SVGA 不写入所选字形；固定字形把文字写成 SVGA 图片，运行时不能动态改字。核对“实际 SVGA 回读”和“设计模拟参考”，勾选确认后进入下一步。预览只覆盖标出的单帧，不是全动画或目标 SDK 验收；长文案、字体、遮罩和其他记录仍需抽检。
4. 生成结果：点击“生成批量交付”。可停止并继续已停止项、仅重试失败项、查看及保存单条交付 ZIP，或“保存已完成 ZIP”。部分成功不会标为全部完成。每条交付包含实际 SVGA、Key 清单、双预览和检查报告，生产不改当前画布。

文字范围或样式不合适时，回编辑器调整并重新选择模板、核对数据与预览。已有旧成果可先保存，再“释放结果 / 新建任务”。

需要关闭后继续：先停止生成，再“保存任务文件（可继续）”，以后从“恢复生产任务…”打开 `.svgabatch`。任务文件包含可编辑源快照、原始文案和成功产物，**不要当作客户交付包发送**。恢复只到上次手动保存点；未保存会话仍在内存，不提供自动崩溃恢复。跨设备需核对字体，恢复的旧预览和包不会重新验收，SHA-256 摘要也不证明来源可信。交付 ZIP、预检 JSON 都不能恢复生产任务。

## 换图：先确认影响范围

在图片资源面板选择素材的“替换图片”，打开“预览素材替换”后，检查“本次替换影响的图层”，再选择适配方式并“确认替换”。

- 仅当前图层：先在图层面板只选中一个引用该素材的图片层。编辑器创建独立资源 Key，只改变该层的资源绑定；保留动画、顺序及文字配置，其他引用层不变。它不会新增图层，可撤销；保存工程及导出的 SVGA 会保留实际拆分效果。动态接入方需使用更新后的 Key。
- 所有引用图层：修改共享资源的替换设置，包括影响名单中的隐藏、锁定层和遮罩引用。锁定图层不等于隔离共享素材，请确认完整名单。

单层拆分要求目标未锁定、原始绑定和图片字节完整；参与遮罩、作为遮罩被引用、矢量绘制（含 `.matte` / `.vector` 或形状帧）的资源不开放单层拆分。此时可考虑所有引用模式，但仍需检查合成效果，不保证任意矢量都能直接换成位图。素材、引用或配置变化会使旧预览失效，需重新操作。

“等比适应”保留完整图片并留透明边，“裁切填充”居中铺满，“拉伸”改变图片比例。确认应用的是预览中的静态 PNG，不改变资源尺寸或图层动画；动态图片会定格为解码时的一帧。

## 命名编组

在图层面板用 Ctrl/Cmd 增减选择或 Shift 连选至少两层，再从“编组操作…”选择“编组所选”，输入组名并确认。组名最多 80 个字符，不可与已有组重名；包含锁定层时需先解锁。

通过“选择命名编组”或“选择整组”恢复成员选区，随后使用已有批量显示、隐藏、锁定、删除等操作；搜索框也支持组名。“重命名编组”作用于整组，“解散编组”只移除组关系，不删除图层。将已有成员再次编组会把它们移入新组。

这是**扁平组织信息**，不改变图层顺序，不是预合成、父子绑定或嵌套组；操作可一步撤销。组关系随 `.svgaproj` 工程保存，运行时 `.svga` 不保存命名编组。

## 多关键帧复制粘贴

展开时间轴图层，操作位置、缩放、旋转、不透明度的附加调整轨道；它们叠加在原始逐帧动画上，本入口不复制或改写原始逐帧数据。

1. 单击选中一帧，Ctrl/Cmd 点选增减关键帧，Shift 点选同一属性轨道内的区间。支持跨属性、跨图层选择，工具栏显示已选数量；Esc 取消选区。
2. 点击“复制关键帧”或在时间轴内按 Ctrl/Cmd+C，移动播放头至目标起点。
3. 点击“粘贴回原图层”或按 Ctrl/Cmd+V：最早所选帧对齐播放头，其他帧保留相对间距、属性、值、缓动和贝塞尔控制点，并分配新 ID。跨层内容按原图层映射。
4. 若只从一个来源图层复制，可另选一个目标层，再点“粘贴至当前图层”。工程切换后禁止直接映射旧图层编号，需显式选择这个单层目标方式。

任一目标冲突、锁定、隐藏或超出有效帧/图层范围，粘贴整组拒绝，不覆盖已有关键帧，也不留下部分写入。成功粘贴可一次撤销。Delete 删除整组选中关键帧，F9 为整组设置出段缓入缓出，均可撤销；任一成员不可编辑时不会只处理其他成员。

复制粘贴快捷键仅在时间轴焦点内生效，不抢占输入框的文本操作。剪贴板只在当前编辑器会话内存中，不写入系统剪贴板、工程文件或跨窗口共享；关闭/刷新后需重新复制。**多选整体拖动尚不支持**，先取消多选再拖动单个关键帧。
