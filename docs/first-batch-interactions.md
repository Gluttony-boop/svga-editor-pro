# 第一批交互改进

## 范围

- 资源单击改为只读详情，保留独立“添加为图层”按钮。
- 详情可查看图片、源尺寸/体积及引用图层，引用按钮只改变选择状态。
- 替换确认明确提示全部引用范围，包括隐藏、锁定和遮罩引用。未增加单图层独立换图、编组、画布拖动或工程草稿功能。
- 撤销/重做按钮与编辑菜单使用当前历史记录的中文操作名称。
- 导出面板与对比弹窗共用结构化状态组件，不再根据文案是否含“失败”决定颜色。

## 验证

自动化检查：`npm run typecheck`、`npm run test:run`、`npm run build:web`。

新增测试覆盖资源共享/遮罩/隐藏/锁定/删除后的引用统计、查询不变性、撤销与重做名称迁移、只读选择，以及六类状态的颜色和可访问角色。

通过 playwright CLI 在本地 Edge 浏览器检查，使用仓库 `test.svga` 与本地图标，未上传到外站：

1. 建立已保存且历史为空的基线，鼠标/键盘打开详情，核对图层数量、未保存标记与历史不变。
2. 详情内 Ctrl+Z 不穿透，点击引用不修改文档。
3. 独立添加按钮新增一层，撤销/重做恢复数量，按钮名称对应“新增图层”。
4. 同资源有两个图层时，替换确认显示全部两个图层，应用后撤销名称为“替换图片”。
5. 生成真实导出预览；通过模拟浏览器保存接口分别验证取消、写入异常、重新写入成功。取消使用中性色，失败保留预览并可重试。
6. 预览生成后修改帧率，显示失效提示并禁用旧结果保存。
7. 检查素材详情和导出弹窗截图，确认内容与按钮布局可用。

保存接口的取消/写入异常属于受控模拟，不等同于已经验证打包后的 Tauri 原生文件对话框。浏览器环境仍出现既有的 Blob Worker CSP 报错，本批没有修改播放引擎或 CSP；导出对比画面可以正常显示。
