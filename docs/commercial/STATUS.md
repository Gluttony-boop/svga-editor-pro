## M1：工程存储与本机恢复已实现，桌面验收待完成

已实现独立 `.svgaproj` 工程格式和 Ctrl+S 保存入口，自包含原始 SVGA、资源、可编辑关键帧、动态文字、尺寸与导出设置；保存工程与导出运行时文件已分开。真实工程下载/重开、重开后的像素一致、继续编辑与撤销，以及坏文件/取消/写入失败保护已通过生产构建的浏览器检查。见 [工程格式与验收](../project-format.md)。

已增加“恢复 / 最近”工程库，采用 `idb` 存储完整归档，而非只记文件路径。完成编辑后自动备份，不暂停播放、不增加历史、不提交文字/画布草稿；可手动备份、下载副本、独立关闭记录和确认后清理。恢复副本最多 5 份且不自动淘汰，最近缓存最多 8 份，总归档容量 256 MiB。多窗口代次和事务保证旧任务不会在清理后复活；缓存维护失败与实际工程写盘结果分开。详见 [本机工程库](../local-project-library.md)。

本轮重新验证：1,537 项编辑器测试、14 项授权服务/真实 D1 协议测试、13 项前端授权策略/客户端针对性测试、16 项完整 Rust 单元测试均通过；TypeScript、ESLint、Web 生产构建和完整 Tauri `cargo check --locked` 通过。Rust 测试含固定 `jose` JWT 的跨语言互操作，授权缓存不再保存独立 claims 副本。生产构建中既有的工程与交付流程证据见各专项文档；未提交、推送、部署 Worker 或触发生产发布。

Windows 原生文件替换执行测试和桌面 WebView 恢复流程尚需完整桌面构建环境（本机缺少 MSVC 链接器，已添加云端原生测试步骤，但本轮未远端运行）。刷新恢复验证不等于系统断电零丢失；本机副本未加密、不是云同步，仍须手动保存重要成果。未标记完整桌面 M1/商业化目标达成。

其后是专业交付包、可恢复批量变体和指定播放器检查。以真实任务省时、返工减少和复用验证付费意愿，不承诺转化率。

## M2：专业交付包首版已实现，目标端验收仍未完成

导出面板新增“专业交付包”：它冻结当前工程快照，生成实际 SVGA，回读实际产物并记录 sprite 来源、Key、文字效果、资源摘要和检查状态；同时提供同一帧的实际文件预览与设计模拟预览。ZIP 默认不附 `.svgaproj`，包含安全序号资源、`manifest.json`、`slots.json`、`report.json`、离线 `README.html`、接入说明和 `checksums.sha256`；勾选后才分享可编辑工程。跨 Key 图片去重在交付任务中关闭，避免动态 Key 合并；目标播放器、字体、真机性能和音频试听明确为未实测。

专业交付包已在 Edge 生产构建中生成并下载；独立 ZIP 检查脚本重新解压并重算所有摘要通过，离线 HTML 报告只加载相对图片、无脚本和外网请求。生成/保存/取消/输入变化/来源顺序不一致/预算超限均有保护。M2 仍未覆盖指定 Android/iOS SDK 的真实全帧接入验收，也没有把报告绿灯当作兼容性承诺。

## 正式上线前需要经营者确认

1. Cloudflare 或其他托管账号、目标用户地区和可达域名；免费额度有限，是否允许升级与预算由经营者决定。
2. 公开安装包发布仓库/CDN 与签名密钥保管方式；私有源仓库令牌不能打进客户端。
3. 价格、设备数、离线宽限、退款/续期/换机流程、代码许可边界。仓库已有 MIT LICENSE，不能擅自将既有公开代码重新定为独占。

这些条件目前不阻塞本地产品能力开发，但会阻塞真实部署、付款和生产版发布。纯客户端无法保证不可破解，不能把签名安全或本地回归通过等同于商业系统已上线。
