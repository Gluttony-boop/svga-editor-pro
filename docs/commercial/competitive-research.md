# SVGA 专业交付工具：竞品与付费价值研究

核验日期：2026-09-20（Asia/Tokyo）。范围为第一方公开网页、官方文档、公开仓库与本地代码；未登录竞品账号、未付费、未上传用户素材，未完成竞品真实文件兼容性或速度对比。本文不是市场份额、成交价格或转化率调查。

## 结论

基础预览、换图、换字和压缩已是成熟供给，不能仅靠“界面像 AE”收费。建议先服务**已有 SVGA、需要频繁改版并交给客户端的设计师与小型动效团队**。产品价值集中在：改动能保存并复用、同一模板能稳定产生多个版本、交付结果有可复核依据。

“更好”必须由同一任务的完成时间、返工率和目标端验收结果证明；“公开资料未提及”不等于“竞品没有”。下列差异均是待实现、待验证的产品方向，不是现有能力宣传。

## 2. 已确认的有限差异与不可下的结论

MotionTools 的批量指南明确限定了两点：批量任务不提供逐文件头像、昵称等动态素材编辑；任务和结果保留于当前页面，刷新/关闭可能丢失。由此可提出**可恢复的模板变体队列**：一次配置 Key 和样式，输入一批昵称/图片，逐项校验、预览、导出并保留任务记录。[证据](https://motiontools.cn/docs/user-guide/batch-conversion/)

这个差异只针对该文档描述的批量工作流。MotionTools 单件编辑支持动态内容；AE 已有数据驱动机制；不能宣传“别人没有批量”“只有我们能换昵称”或“首创数据驱动”。

“目标播放器交付报告”和“持久化 SVGA 编辑工程”在本轮查阅的 MotionTools、MeeWoo 公开页面中未找到完整工作流证据，结论是**未确认**，不是确定缺失。PAG 已有性能诊断，因此“有性能面板”本身也不是差异。可竞争的细节是：对选定播放器版本，用真实产物、可追溯参数和测试记录，降低交接返工。

官方 SVGA Web 播放器仓库于 2023-02-06 归档，官方历史兼容列表不能替代当前业务端验收。新的兼容性功能应准确记录维护分支、版本、平台和检查项，不发放“全平台兼容”虚假绿灯。[官方仓库状态](https://github.com/svga/SVGAPlayer-Web)

## 3. 当前项目基线与重要缺口

此处是 2026-09-20 调研开始时的代码/文档基线；之后同一目标模式中的实现以测试和对应功能文档为准。

| 能力 | 当前基线 | 对商业交付的影响 |
| --- | --- | --- |
| AE 风格图层编辑 | 已有单层关键帧、画布变换、多层整段调整、时间编排、撤销 | 足以解决“没有 AE 源文件时的小改动”；不宜扩张为完整 AE 替代品 |
| 画布与导出一致性 | 已有尺寸修改、锁定比例、安全上限、真实产物比较 | 是可靠性基础，不应作为新的收费拦截点 |
| 图片 Key 与文字模拟 | Key 精确匹配；文字用途是命名提示；模拟文字不写进 SVGA，可另存 JSON | “预览好看”不等于“开发拿文件即能显示文字”；需要明确交付类型 |
| 工程保存 | `src/App.tsx` 的保存流程构建 `.svga`；关键帧文档说明结果会烘焙；文字文档说明配置仅当前会话保存 | 再打开产物无法继续编辑原稀疏轨道，文字配置也无法直接回灌；这是复用与留存的高优先级缺口 |
| 商业许可声明 | `package.json` 与 README 标注 MIT，但根目录未找到 README 链接的 `LICENSE` | 收费前需核对自有代码、历史公开许可和第三方授权；不能擅自删掉原许可或声称公开旧版都已禁止使用 |

本地依据：[关键帧工作区](../keyframe-workspace.md)、[文字模拟](../text-preview.md)、[画布尺寸](../canvas-size.md)、[现有源码研究](../meewoo-source-research.md)、`src/App.tsx`、`src/stores/editorStore.ts`、`package.json`。这是技术与文档问题清单，不替代法律意见；本轮未修改许可。

## 4. 首批客户、任务与验收

| 优先客户 | 要完成的任务 | 当前替代方案 | 产品必须证明什么 |
| --- | --- | --- | --- |
| 直播礼物/会员特效设计师 | 保留现有运动，改头像昵称、位置、尺寸并交付 | 回 AE 找源工程，或在在线工具重复修改 | 无源工程也能完成指定改版；当天与次日继续编辑不丢状态 |
| 外包/小型动效工作室 | 同一套模板做多个客户、渠道、语言版本 | 手工复制文件、逐件换素材并核对命名 | 批量结果一一对应；错误能定位到行/Key；局部重做不覆盖已确认结果 |
| 客户端/技术美术协作者 | 判断文件是否符合特定业务播放器与资源预算 | 手写脚本、截图对照、设计与开发来回询问 | 收到明确 Key、尺寸、限制和产物校验值；“未测试”不能误报通过 |

优先不服务：从零制作复杂三维/特效的 AE 用户、泛视频剪辑用户，以及仅偶尔看一眼 SVGA 的用户。后者可以是免费入口，但未必有持续付费需求。

## 5. 前三项可收费价值假设

1. **模板复用与批量变体**：持久化工程是所有用户的可靠性底座；收费候选是可复用字段模板、CSV/JSON 驱动的多版本队列、失败项重试与续做。比较人工 20 个版本与批处理的总耗时、错配率和次日续做成功率。
2. **可复核的交付包**：将 SVGA 产物、动态文字配置、预览图、Key 清单、资源预算、文件摘要和目标播放器说明统一打包，模板与项目级交付规范可复用。比较开发第一次接入所需追问数、交接耗时与退回次数。
3. **目标环境检查与可解释优化**：先做静态体检和真实导出回读，再对明确的播放器版本做差异检查；保留超限原因、测试平台及未测项。比较“导出成功但接入失败”的比例，不拿估算内存替代设备峰值实测。

三项均需要试用任务验证，不能由竞品功能列表推算愿付价格或承诺转化率。实施顺序、套餐边界与实验口径见 [产品路线图](product-roadmap.md)。

## 6. 研究方法与后续核验

- 本轮使用 web 读取官方文档。MotionTools 编辑器、MeeWoo 主站/帮助的 web 文本抓取失败后，以只读 HTTPS 请求确认响应及公开内容；两站返回 200。该过程不是完整浏览器交互验证。
- `https://svga.io/` 的文本抓取超时；直接访问只返回跳转/校验壳，未据此评价产品能力，改用可访问的 PAG 官方资料补充交付工具比较。
- 每次发布前重查竞品文档；登录后额度、真实价格和受限功能由有权账号的人补充，不绕过付费或访问控制。
- 下一步建议邀请 5–8 名符合上述任务的用户，用获授权的样例完成同一任务。记录冷启动/热启动、文件体量、P50/P90 完成时间、失败重试和完成质量；让用户选择实际愿购买的方案，而非只回答“喜不喜欢”。
- 竞品网页可访问不意味着源码可复制。本轮未复制其实现、品牌或素材。后续复用任何第三方代码，应另记来源、版本和许可义务。
