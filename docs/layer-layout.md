# 精确排版：对齐与等间距分布

## 操作入口

选中一个或多个图层，进入右侧“属性 → 对齐与分布”。

- 对齐支持左、水平居中、右、顶、垂直居中、底六个方向。
- “参考范围”可选当前选区或画布边界。单图层默认对齐到画布，多选默认对齐到当前选区。
- 等间距需要至少三个可编辑图片图层，按水平或垂直边缘间距排列，不是简单平均中心坐标。
- 相对选区分布保留整体外接范围；相对画布分布把首尾外边缘放到画布两端。
- 宽度或高度总和超过参考范围时，计算负间距并显示重叠提示，操作仍可一次撤销。

## 数据语义与保护

边界取当前帧、所有已有缩放/旋转/镜像/倾斜之后的世界外接矩形，不按透明像素、遮罩后的轮廓或视觉光晕计算。排版仅调整每层 `canvasTransform.x/y`，不修改缩放、角度、素材、源帧或动画轨道。

操作开始先暂停播放并读取最后实际绘制帧。排版结果是各层的整段位移，而非逐帧约束，因此后续播放仍保留原动画；不同图层在其他帧可能不再对齐。

选区含锁定、隐藏、非图片或当前帧缺少有效边界的成员时，整次操作拒绝，不跳过某些成员偷偷排版。无效数值、非有限尺寸和溢出也会拒绝。

每次实际改变只生成一条带操作名称的撤销记录，保留选区、当前帧与未选中图层。重复执行已满足的排版不会改变 dirty、历史或已有重做记录。若拖动尚未结束，先提交拖动，再把排版作为独立操作记录。

## 实现取舍

沿用现有 Moveable/Selecto 画布与选区。排版是对 SVGA 当前帧几何的轻量位置计算，没有为八种算式引入新的重量级库或另一套文档模型。

## 验证

- 类型检查通过，全量 33 个测试文件、327 项测试通过；Web 构建通过。
- 核心 58 项排版测试覆盖六向对齐、不同尺寸间距、旋转/镜像/倾斜、稳定排序、真实 ImageResource、去重、无操作判定、负间距和无效参数。
- 状态 20 项测试覆盖单次撤销/重做、只读选择与源动画保护、未选中项不变、已有 redo 保留、完整拒绝、同步暂停实绘帧、拖动后排版。
- Playwright + 本地 Edge 使用临时三个不同尺寸图层验证：单层画布参考、选区顶对齐/等间距、无操作反馈、画布首尾与等间距、撤销重做、锁定保护、播放中排版、负间距提示。
- 使用真实生成的 SVGA 字节重新解码，核对三个图层矩阵与预览一致，误差小于 0.002。保存接口由内存模拟接收实际字节，未替代打包后的 Tauri 原生对话框验证。
