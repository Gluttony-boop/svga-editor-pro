# 界面优化 · 2026-09-08

范围：现有本地 React/Tauri 编辑器的视觉与布局，不迁移平台、不发布云端、不修改 SVGA 编解码或压缩参数语义。

## 改动

- 深蓝色层级调整为灰黑工作区，统一输入、边框、滚动条与柔和粉色强调；增加辅助文字对比度，正文小字号由 11/12 px 调整为 12/13 px，主按钮使用深色字。
- 图层行保留 72 px 虚拟行高，压缩拖拽/缩略图/操作区占宽，为图层名留出更多空间；元信息不再折成竖排。
- 左侧默认宽 320 px，右侧默认宽 340 px，并限制占据窗口的比例；顶部提供重置面板尺寸。
- 右侧改为属性、插槽、导出标签，单一面板占满检查器滚动区域。切换仅隐藏视图，不卸载组件，因此保留配置和导出预览缓存。支持标签键盘导航及 Ctrl+E 跳转并聚焦导出。
- 顶部直接提供保存、导出；标题栏展示文件名和未保存状态；空白画布提供居中的文件选择入口和快捷键提示。
- 倍速按钮改为下拉选择，播放栏可以换行；“适应画布”测量浮动工具条高度，为其预留空间。仍保留背景、缩放、沉浸预览及渲染器操作。
- 增加统一键盘焦点描边与减少动态效果偏好支持。

## 验证

- 80 项现有测试、类型检查、lint、Web 生产构建通过。
- 在生产版页面验证空状态、文件载入、顶部导出、三个标签的鼠标/键盘切换、预设保持、生成预览后切换标签仍可复用、F9 与 Ctrl+E 联动。
- 1440×1000 与 1024×720 截图检查；窄窗口检查无页面横向溢出、图层名称按钮宽度大于 60 px、高级配置有独立滚动区域、播放速度可切换。点击适应画布后检查 Canvas 底部位于工具条上方。
