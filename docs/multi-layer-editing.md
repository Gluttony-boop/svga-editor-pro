# 多图层选择与整体变换

## 使用

1. 在左侧图层列表或时间轴名称上 Shift/Ctrl/⌘ 单击，追加或移除图层。单击恢复单选；最后选中的图层作为主图层。
2. 在画布空白处拖动框选，Shift 拖框追加（已选中项重复覆盖时切换选择）；Shift 单击图层同样可以切换选择，Alt 单击仍用于重叠候选的穿透单选。
3. 多选显示整个选区的控制框和各图层轮廓。拖动控制框移动，拖动手柄等比缩放或旋转；W 仍可旋转选中区域，H/中键只移动预览视口。
4. 右侧属性显示选区摘要，避免误把主图层的单层数值当成全组选区值。“仅保留主图层”可恢复单层参数编辑。
5. 一次整体手势只产生一条“整体变换：N 个图层”历史。Esc 或窗口失焦取消本次手势；拖动中撤销只取消该手势，之前的编辑仍保留。

框选接入 [React Selecto](https://github.com/daybrush/selecto) 1.26.3（MIT）；变换控件沿用 React Moveable。许可随静态构建保存在 `third-party/selecto-LICENSE.txt` 和 `third-party/moveable-LICENSE.txt`。

## 语义与限制

- 这是临时多选，不写入永久编组，也不自动创建关键帧。
- 手势开始时以当前已绘制帧的选区中心为固定基准，将同一个平移、等比缩放或旋转应用到各成员；最终仍保存为各图层的整段变换，因此后续各层保持原有动画，不会建立跨帧父子约束。
- 整组仅支持等比缩放。对已经旋转的多个图层做非等比缩放会引入额外倾斜，当前 `CanvasTransform` 模型不能无损表达，所以不提供看似可用但导出不一致的手柄行为。单图层非等比缩放仍可使用。
- 画布框选按素材当前仿射四边形命中，不是按透明像素或遮罩裁切后的轮廓。选框触及该四边形即算命中。
- 框选跳过隐藏、锁定、非图片和当前帧无可用几何的图层。若从列表选区中包含这些成员，则禁止整个选区变换，而非默默仅变换其余成员。
- 选择/筛选/背景查看不修改文件或历史；删除和恢复图层时选区去除失效 ID，撤销/重做恢复对应选区。
- 从资源检查器定位引用仍恢复单选，清除图层筛选并定位目标。

## 验证

- `npm run typecheck`、`npm run test:run`、`npm run build:web`。
- 新增 42 项测试：组变换数学 11、多选状态事务 26、选择辅助 5；全量 248 项通过。覆盖倾斜源矩阵、镜像/负缩放、已旋转成员、未参与图层不变、原子提交/取消、主图层与去重、跨文件同 ID 隔离、兼容原单选 API。
- Playwright + 本地 Edge 用真实样例与临时三图层布局验证：列表和时间轴多选高亮，画布追加选择、精准框选、Esc 取消后 Shift 追加、整体移动/缩放/旋转、拖动中撤销后选框复位、含锁定成员禁用、播放中开始框选同步实绘帧。
- 导出真实 SVGA 字节并回读，三层各自的 `a/b/c/d/tx/ty` 与预览几何比较，误差小于 0.002。文件写入接口采用内存模拟接收生成字节，尚未替代原生 Tauri 保存对话框验收。
