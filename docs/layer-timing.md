# 图层时间编排

## 功能范围

右侧属性面板的“时间编排”用于调整图片图层在输出时间轴上的整体出现时间，支持：

- 提前或延后选中图层指定帧数。
- 按图层列表顺序依次错开多个选中图层。
- 将选中图层的时间偏移重置为 0。
- 在操作会超出当前动画尾部时，选择自动延长总帧数，或保持总帧数并拒绝本次操作。

时间偏移只改变“源帧映射到哪个输出帧”，不会重写源动画的关键帧、裁剪区间或图片数据。时间轴条带、关键帧标记、实时预览、导出预览和最终 SVGA 导出使用同一套映射，因此画布看到的结果与导出结果一致。

## 操作语义

- 偏移为正数时图层延后出现，为负数时图层提前出现。
- 面板中的范围使用从 1 开始的帧号，偏移量使用 `F` 表示帧数。
- 图层偏移后的开始帧不能早于输出第 1 帧。
- “依次错开”以首个选中图层当前开始时间为锚点，按图层列表顺序应用固定间隔，至少需要选择两个图层。
- 关闭“延长总帧数以保留尾部”后，只要任一图层会超出动画尾部，整次操作都会被拒绝。
- 重置偏移不会自动缩短动画总帧数，避免误删已安排的尾部空间。
- 一次时间编排只产生一条撤销记录；无实际变化时不创建历史记录。

## 安全约束

- 锁定、隐藏、非图片或时间数据异常的选中项会使整次操作被拒绝，不会只修改其中一部分。
- 具有遮罩关系的图层在提前、延后或重置时按完整关联组处理，防止素材与遮罩错位。
- 遮罩关联组暂不支持“依次错开”，因为分散关联成员会改变合成语义。
- 音频轨道暂不随图片图层偏移，面板会明确提示这一限制。
- 输出时间不在图层源裁剪区间内时保持透明，不使用最后一帧填充空白。
