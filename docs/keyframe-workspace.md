# 关键帧工作区

本轮借鉴 AE 的图层属性展开、播放头定位、关键帧菱形与缓动操作。目标是 SVGA 的素材调整与动画再编辑，并不是完整复刻 AE；不把原文件的每个采样帧冒充可编辑关键帧。

## 快速完成一个动画

1. 打开 SVGA，在左侧图层列表或时间轴选择要修改的图片图层。
2. 点击画布工具条“◆ 关键帧”或检查器的同名模式按钮。
3. 在开始帧点击“记录当前帧全部属性”，或在时间轴属性名称旁点击 ◆，只记录该属性。
4. 将播放头移动到后面的帧，拖动画布图层，或在检查器输入位置偏移、缩放百分比、旋转角度、不透明度。输入按 Enter 或失焦应用，Esc 放弃草稿。
5. 播放查看中间帧的插值。选中时间轴菱形，可拖动改变时间，或者输入精确的关键帧帧号。
6. 为选中关键帧选择线性、缓入、缓出、缓入缓出或保持。缓动作用于此关键帧到下一个关键帧之间。
7. 在导出面板生成真实 SVGA 预览，再保存确认后的产物。

第一次在后续帧直接修改尚无关键帧的属性，会在该层可编辑起点补一帧中性值；因此不会因为只修改后面的值而让整个片段突然整体跳变。显式插入的首个关键帧则遵循首尾停留规则，首帧之前和末帧之后保持最近关键帧的值。删除一条属性的全部编辑关键帧，会恢复该属性的中性叠加值。

## 两种编辑模式

| 模式 | 修改范围 | 是否记录关键帧 |
| --- | --- | --- |
| 整段调整 | 修改全片段的基准位置、缩放、旋转和透明度，保留已有运动 | 否 |
| 关键帧 | 修改当前输出帧的附加位置、缩放、旋转和透明度 | 是，重复编辑同帧更新已有关键帧 |

关键帧位置是画布坐标中的附加偏移，缩放 100%、旋转 0°、不透明度 100% 为中性值。整段变换与关键帧一起影响最终图像，但它们独立保存。画布中的单层移动、缩放、旋转和方向键微调遵循当前模式；每次完整手势只生成一条历史，Esc 取消手势。

多选图层可在时间轴主工具栏批量插入属性关键帧；当前帧不合法、含锁定或隐藏层时整次拒绝。多选的画布整体移动、缩放与旋转仍需使用“整段调整”；关键帧画布手势暂时只支持单层。

## 时间轴操作

- 时间轴默认每个图层只占一行，避免多选时把属性轨道误认为新增图层；点击左侧箭头展开四条编辑属性，或使用属性筛选集中处理一个属性。多选只改变选区，不创建图层。
- “仅选中图层”减少无关轨道，属性筛选可集中处理一个属性。
- 时间轴获得焦点时，`P / S / R / T` 筛选位置 / 缩放 / 旋转 / 透明度，`U` 仅显示有编辑关键帧的属性。
- 选择菱形后按 `Delete` 删除关键帧，`F9` 设为缓入缓出；时间轴以外的 `F9` 仍为沉浸预览。
- 左右方向键逐帧，Shift 加速十帧，Home / End 跳首尾；Ctrl/Cmd + 滚轮缩放，Shift + 滚轮横移。
- 拖动关键帧期间只显示落点预览，释放时才提交；Esc、窗口失焦或指针取消会放弃移动。
- 已有同属性关键帧的落点、图层裁剪之外或动画范围之外均不可放置，不会覆盖其他关键帧。
- 面板帧号从 1 开始；底层关键帧在源时间中保存，图层“时间编排”的偏移会同步反映到显示和导出。

## 一致性与修复

- 原 SVGA 的逐帧矩阵、裁剪路径、遮罩和旧预设保留；新编辑动画独立叠加。
- 两个正式预览渲染器的缓存签名包含关键帧数据，同一帧改值会刷新画面。
- 整组变换使用含当前关键帧偏移的真实中心，避免有动画时组旋转和缩放偏离。
- 复制普通导入图层会保留原逐帧运动与关键帧，并深拷贝图形数据；副本拥有新的关键帧 ID。
- 与遮罩有关联的图层暂不允许单独复制，菜单明确给出原因，防止错误的合成结果。
- 复制图形导出前转换 Protobuf 枚举，避免矩形等图形类型在编码后改变。
- 输入草稿绑定图层、当前帧与模式，切换上下文不会把旧草稿提交给新目标。

## 当前边界

本轮没有图形曲线编辑器、关键帧多选/复制粘贴、表达式、父子图层、3D 或任意锚点编辑。已有贝塞尔参数可以保留，但没有提供未完成的控制柄界面。音频不会自动跟随图层时间偏移。导出的 SVGA 会烘焙逐帧结果，不携带编辑器专用的稀疏关键帧工程元数据；重新导入仍是正常 SVGA 动画。

最终工作区类型检查、Lint、44 个测试文件共 588 项测试、Web 生产构建通过；GitHub 打包脚本另有 25 项离线测试通过，未真实触发远端构建。测试数量包含工作区同时完成的历史面板回归。

Playwright 在 Edge 中验证了：单层插帧、位置/缩放/旋转中间值、画布移动/缩放/旋转手柄、单次手势撤销重做、菱形拖动/Esc取消、冲突拒绝、F9缓动、Delete删除、批量插帧保持多选，以及播放中先暂停再记录实际帧。生产构建也能生成并解码实际优化/未优化 SVGA 预览。截图保存在忽略目录 `output/playwright/`；这些检查不等同于 Tauri 安装器或所有第三方 SVGA 播放器的验收。
