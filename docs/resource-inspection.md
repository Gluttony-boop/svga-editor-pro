# SVGA 素材检查与体检

## 入口与行为

- 左侧“图片资源 → 体检”汇总当前文件的源图成本与引用关系。摘要是整个文件的统计，不受资源搜索影响。
- “全部 / 共享 / 遮罩 / 未引用 / 已配置 / 高内存”可与 Key 搜索组合使用；按钮数字为全文件分类数量。清除筛选恢复完整列表。
- “已配置”包括文字和图片插槽。资源卡片显示当前引用数量、遮罩或高内存标签。
- “内存↓”按源图尺寸估算排序，未知尺寸排在最后；统计单独显示未知数量。
- 单击资源进入素材检查：源图与替换图片对比、透明格/黑/白背景、复制 Key、提取图片、替换入口和引用列表。
- 文字插槽不伪装成已渲染文字预览，明确提示去动画预览查看，提取按钮标注“提取源图片”。
- 点击引用会选中图层，清除图层搜索/状态筛选并滚动到目标。不会改变显示、锁定、播放帧或文档历史。
- 检查报告仅导出计数、尺寸、体积、分类、资源 Key、图层引用等元数据；不包含图片字节、资源 URL 或额外的本地文件路径字段。Key 和图层名称仍属于报告内容，分享前应自行确认。

## 判断边界

- 引用索引以当前编辑图层为准：包括隐藏/锁定图层、复制图层和遮罩引用，删除的图层不计入。同一图层的图片和遮罩引用同一 Key 时只计一个图层。
- 未引用不意味着可安全删除，外部业务仍可能依赖动态插槽 Key。本功能不自动清理或修改文件。
- 待核对引用 Key 是“当前资源列表没有对应图片”的结构事实，不直接判定损坏；形状或运行时注入素材可能有此情况。
- 解码估算为每张源图 `width × height × 4`，不含替换图、GPU、缓存或进程其它内存。未知尺寸不当作零占用。
- 单图估算达到 4 MiB 会列入高内存排查，这不是任何平台硬限制。调色板压缩减小编码体积并不必然降低该估算；降采样才会改变像素数。
- 文件头优先于占位 MIME，防止导入的 JPEG/WebP/GIF 被错误显示为 PNG。

## 验证

- `npm run typecheck`
- `npm run test:run`：涵盖原有用例、用途计数、缺失/遮罩、阈值边界、未知尺寸、特殊 Key、报告白名单、索引不变性、定位事件与监听清理。
- `npm run build:web`
- 使用 Playwright CLI + 本地 Edge 检查真实 `test.svga` 和临时内存构造的 183 图层/92 资源样本：筛选与内存排序、长列表滚动后切换筛选、定位隐藏锁定图层、缺失引用定位、源图/替换图不同、背景检查与只读状态、通过检查器选择本地图标并完成替换/撤销。
- 浏览器保存接口采用受控模拟，验证报告和图片提取的取消/重试/成功反馈及导出报告不包含图片数据；不能替代 Tauri 原生文件对话框测试。
- 截图保存在 `output/playwright/professional-audit.png`、`professional-audit-fixture.png`、`professional-replacement.png`。

浏览器开发模式仍会记录既有 Blob Worker CSP 错误，本轮未更改渲染引擎/CSP；不要据此把素材体检视为完整播放性能验收。
