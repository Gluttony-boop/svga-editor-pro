# 首页任务示例及授权

首页的“换头像昵称”“压缩到指定大小”“批量生成”“检查交付”使用 `src/core/task-examples.ts` 在本地生成的原创几何示例。

这些示例的位图和逐帧动画数据以 **CC0 1.0 Universal（公共领域贡献）** 提供：允许用于个人练习、修改、商用设计和交付，无需署名。不包含第三方头像、品牌、商标、竞品素材、字体文件或网络下载内容；示例里的头像由圆和轮廓构成，不对应真实人物。生成器代码及项目其他代码仍沿用项目 MIT 许可，CC0 只适用于这里生成的示例素材与动画数据。

## 示例内容

| 任务 | 视觉主题 | 适合体验 |
| --- | --- | --- |
| 换头像昵称 | 浅色靛蓝卡片 | 图片替换范围、文字预览、画布编辑 |
| 压缩到指定大小 | 深色青绿网格 | 图片缩放、体积比较、压缩预览 |
| 批量生成 | 暖色分段卡片 | 同一模板更换多份昵称、生成交付包 |
| 检查交付 | 深色紫色卡片 | 图片 Key、文字 Key、交付预检和结果核对 |

每份动画为 520 × 300、24 FPS、48 帧。`avatar` 被两个不同图层引用，用于体验“仅当前图层 / 所有引用图层”的区别；`nickname_text` 是可模拟文字的图片占位 Key。底图保留二倍分辨率与细微纹理，压缩示例能观察尺寸缩减和编码质量的变化，不保证任意目标体积都能无损达到。

文字由编辑器按用户系统可用字体实时显示。示例不分发字体；若在自己的交付中嵌入或分发其他字体、头像和品牌素材，需要另行确认相应权利。示例的公共领域贡献不涵盖用户后来导入的内容。

所有生成过程均在本机内存进行，不上传素材，也不访问外部服务。
